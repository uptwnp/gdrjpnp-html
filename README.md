## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile browsers.
- **Interactive Lead Form**: Quick price details inquiry form.
- **Rich Media**: High-quality imagery, video highlights, and gallery sections.
- **Highlights & Amenities**:
  - 🏡 Premium Residential Plots (100 to 180 sq. yards)
  - 🏰 20,000 Sq Ft Clubhouse with Spa, Gym, & Swimming Pool
  - 🌿 Japanese Miyawaki Forest
  - 🛡️ 5-Tier Security System
  - 📐 3-Side Open Plots (up to 4 floors allowed)
